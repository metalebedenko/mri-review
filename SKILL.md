# Разбор МРТ

Экспериментальный исследовательский процесс с прослеживаемыми источниками и калькулятором геометрии по вручную заданным точкам. Клиническая валидация не проводилась. Это не автономная система диагностики, медицинской сортировки или выбора лечения. Наблюдения ИИ по изображениям требуют проверки квалифицированным специалистом; ссылки на руководства не подтверждают точность самого скилла.

**Только текст.** Объясни формулировки в пределах предоставленного описания. Наблюдения и размеры припиши врачу. Если данных для сравнения нет, динамика неизвестна. Ответь в чате, если пользователь не запросил файл. Для отчёта по описаниям укажи документ и дату, если она известна.

**Есть задача разобрать снимки.** Определи вопрос и [анатомический профиль](references/anatomy-profiles.md). Для поясницы есть [отдельный профиль](references/lumbar-spine.md), для других областей при необходимости подбери первичные руководства. По [процедуре просмотра](references/workflow.md) проверь пиксели, геометрию и фактический охват. Запиши источники наблюдений по каждому исследованию. Сравнивай только сопоставимые серии. Укажи, какие выводы или клинические данные были известны заранее.

- Перед измерением проверь [точки, маску, плоскость и единицы](references/measurements.md). Для расстояния по уже выбранным точкам доступен [калькулятор](scripts/measure_landmarks.py). Он не читает DICOM, не интерпретирует изображения, не выбирает анатомию и не вычисляет объёмы или диагностические категории.
- Для диффузии, перфузии, ангиографии, спектроскопии, карт или cine смотри [специализированные серии](references/specialized-mri.md).
- Для проектного разбора сохрани отчёт, измерения, источники и границы просмотра по [правилам отчёта и сравнения](references/reporting-and-followup.md). Для DOCX/PDF проверь фактический рендер.

Данные пациента, DICOM и реальные разметки остаются в его проекте. Калькулятор сохраняет входную запись в результате и не обезличивает её. В публичные примеры включать только синтетические данные. Установки, изменение прав и передача медицинских файлов внешним сервисам требуют отдельного основания в задаче. Результат предназначен для обсуждения с врачом.
